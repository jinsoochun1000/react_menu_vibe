# react_claude

React 기반 상단 FullDown 메뉴와 좌측 아코디언 메뉴 예제입니다.

## 실행

```sh
npm install
npm run dev
```

배포용 빌드: `npm run build` / 빌드 미리보기: `npm run preview`

Windows PowerShell에서 npm 스크립트 실행이 제한되면 `npm.cmd`를 사용하세요.

## 구현 기능

- 상단 메뉴 hover 또는 클릭 시 전체 5개 카테고리, 25개 하위 메뉴 펼침
- 외부 클릭, 포커스 이탈, Escape 키로 상단 메뉴 닫기
- 좌측 메뉴 펼침/접힘 및 선택 메뉴 동기화
- 상단 메뉴 선택 시 좌측에는 해당 카테고리만 표시하고 하위 메뉴를 자동으로 펼침
- 하위 메뉴 선택 시에도 소속 카테고리로 좌측 메뉴 동기화, 홈 클릭 시 전체 메뉴 복원
- 하위 메뉴 선택 시 제목, 경로, 본문 변경
- 메뉴 검색, 최근 방문 메뉴 최대 4개 표시 (현재 세션 메모리)
- 모바일 좌측 메뉴 및 반응형 카드 레이아웃

## DB 메뉴 연결

`src/menu.js`의 데이터를 아래 구조의 API 응답으로 교체하면 됩니다.

```js
[{ id: 'category-1', name: '메뉴1', children: [{ id: 'page-11', name: '메뉴11' }] }]
```

각 메뉴에는 고유하고 안정적인 `id`를 사용하고 DB의 메뉴 명칭을 `name`에 매핑하세요. 실제 API 연결 시 로딩/오류/빈 데이터 처리를 추가하고 서버에서 정렬한 메뉴 목록을 전달하세요. 현재 예제에는 백엔드 및 개별 메뉴 업무 기능이 포함되어 있지 않습니다.

폰트는 Google Fonts의 Noto Sans KR을 사용하며, 네트워크 연결이 없으면 시스템 sans-serif 폰트로 표시됩니다.
