# react_copilot

React + Vite로 구현한 FullDown 메뉴 예제입니다.

## 기능

- 상단 메뉴 메뉴1~메뉴5 제공
- 상단 메뉴 선택 시 소속 하위 메뉴만 좌측에 표시
- 좌측 하위 메뉴 선택 상태 표시
- 데스크톱과 모바일 반응형 레이아웃
- 메뉴 데이터와 화면 로직 분리

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음 명령으로 확인할 수 있습니다.

```bash
npm run build
```

## 메뉴 데이터 교체

현재 메뉴 데이터는 `src/data/menuData.js`에 있습니다. 이후 DB API를 연결할 때 이 파일의 정적 배열을 API 응답 상태로 교체하면, 화면의 상단/좌측 메뉴 렌더링 로직은 그대로 사용할 수 있습니다.
